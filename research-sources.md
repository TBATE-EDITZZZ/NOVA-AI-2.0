# External implementation sources

- Google AI Studio, Gemini API `generateContent` reference: https://aistudio.google.com/api-reference/generate-content/generate-content. The page documents `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`, text in `contents[].parts[].text`, response text in candidate content parts, and shows a Flash model example. The server-only NOVA integration follows the REST shape and keeps the credential out of browser code.
- NASA, “Cosmic Cliffs” in the Carina Nebula (NIRCam Image): https://science.nasa.gov/asset/webb/cosmic-cliffs-in-the-carina-nebula-nircam-image/. Official page title; release date July 12, 2022; image credit NASA, ESA, CSA, STScI. Page identifies the subject as the star-forming region NGC 3324 in the Carina Nebula, roughly 7,600 light-years away, and explains that hues are mapped from infrared filters.
- NASA image download page lists a 2,000 × 1,158 PNG at https://assets.science.nasa.gov/content/dam/science/missions/webb/science/2022/07/STScI-01GA6KKWG229B16K4Q38CH3BXS.png/jcr:content/renditions/2000x1158.png. The local image was sourced through image search from that official NASA asset and converted, aspect-ratio-preserving, to WebP for mobile loading.

Science API endpoints wired in the application: USGS global all-day GeoJSON feed (https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson); NASA Astronomy Picture of the Day (https://api.nasa.gov/planetary/apod); Open-Meteo forecast endpoint (https://api.open-meteo.com/v1/forecast); Crossref works metadata (https://api.crossref.org/works). These are displayed only with returned values, provenance and application retrieval time; provider failures are not replaced with mock live measurements.

- Google AI Studio, Latest Gemini models: https://aistudio.google.com/docs/latest-model. The authenticated model catalog listed `gemini-3.8-flash` with `generateContent`, but its minimal generation request exceeded a 45-second timeout in this runtime. A minimal `gemini-3.1-flash-lite` request succeeded in 1.6 seconds and the NOVA tRPC route subsequently passed end-to-end. `gemini-2.5-flash` returned Google's retirement response for new users. The server now defaults to `gemini-3.1-flash-lite` and still accepts a server-only `GEMINI_MODEL` override. Model availability and latency can vary by project and time.
